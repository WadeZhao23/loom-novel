把一队分工 Agent 织成一条**写小说的流水线**,做成桌面客户端。读你的"外置大脑"一键跑出一章正文;你手改,它**越写越像你**。你的书和写作指纹都存在本地,Loom 自身不收集、不上传;只有用 AI 写作时,才把必要上下文发给你选的模型(DeepSeek 云端 / 本机 claude·codex / 任意 OpenAI 兼容供应商)。自带 DeepSeek key,按字数计费。

## 0.5.1 有什么

**「学改法」上一版其实学不到东西。这版真的能学了。**
上一版的做法是:把「AI 交的那份细纲」和「你改成的那份」两份原文整个丢给模型,让它自己去比。
可两份各一千多字、真正的差异只有 40 行里的一两行——它找不着,于是每次都回你「没归纳出反复出现的改法」。
这版改成:**先由程序把差异逐行算出来**(你删了哪几行、加了哪几行、把哪行改成了什么),再把这份
算好的差异交给它。同一个模型、同一批稿子,从「学不到」变成当场归纳出你的习惯。

真机实测(样例书跑三章、每章手改细纲):作者一共删掉 5 处「情绪:」标注行、2 处「向读者许的承诺」行。
改之前它回「无」;改之后它归纳出——
> - 不在分镜细纲中单独写出「情绪」标注行;将情绪融入场景动作与对话描述中。
> - 不写「向读者许的承诺」这类预告下一章钩子的行;钩子信息只通过「章末钩」体现。

(这是 Loom 第二次栽在同一个地方:0.3.7 那版发现「让模型自己数字数」根本不管用,
把数数交还给了代码。这次是同一个道理换了个形状——让模型自己找差异,也不管用。)

**镜台能撤销了。** 上一版说「学到的写法随时能一键撤销」,但客户端里其实没有那个按钮——
只能出去用外部编辑器改 `agents/<角色>.md`。这版把按钮补在镜台的「它跟你学到的写法」那一行:
撤销**最近一次**、基座提示词不受影响。没有可撤的时候按钮不出现,不给你一个点了才说
「没有备份」的假入口。

**「自检」不再冤枉你。** 如果你的 key 是在设置里连一次、全局记住的(而不是每本书单独填),
那么每开一本书点「启动自检」,它都会红着脸告诉你「DEEPSEEK_API_KEY 没配」,还教你去这本书的
`.env` 里补一行——**而那正是「全局记住」这个功能要免掉的动作**。写章其实一直是好的,
只有自检在说瞎话。这版让自检认的范围和真正取 key 的范围对齐。
(这个毛病和「全局 key」是同一版一起发的,一直带到今天。)

**「学改法」不再给你一个办不到的承诺。** 以前你让伙伴学设定师/写手/编辑/润色师的改法,
它回一句「证据不够,再写几章再说」——可那四个人格**再写一百章也不会够**:学改法比对的是
「AI 交的那份」和「你改成的那份」,而只有大纲师的细纲是你能在盘上直接改的东西。
现在它直接说清今天能学谁,不再让你白等。顺带把「证据不够」那句写实在:
光写章不够,得动手改它交的细纲——照单全收的那一章没有可比对的差异。

老书零迁移。

## 0.5.0 有什么

**新增「镜台」:看得见它有多懂你。** 侧栏多一个入口,一屏两条曲线——**改写率**(你把它写的
改掉了多少,也就是它像不像你)和**增删率**(你往里加了多少、删了多少,也就是它懂不懂你要什么)。
下面还摊开写作指纹现在学到了几条规则、它认的 anchor 原句,以及每个人格跟你学到的写法。
一句诚实话:曲线只画你 learn 过的章。没 learn 的章不算 0%,那是「还没看」不是「不用改」
——把它算进去这个数就虚高了,虚高一次就再也不可信。

**它开始跟你学改法了。** 以前你手改稿子,只有写作指纹在长;现在你跟「伙伴」说一句
「学一下大纲师的改法」,它会去比对**你实际把 AI 的细纲改成了什么**,蒸出一两条增补,
做成候选卡给你看。你点头才落盘,落的是「个人增补」区、**基座提示词一个字不动**。
它学的判据只有一个:你实际改成了什么——不打分,不猜「哪样更好」。

关于这件事,三句实话:
- **要从这一版之后新写的章开始攒证据。** 它比对的是「AI 交的那份」和「你改成的那份」,
  而前者是这版才开始留底的。你已经写完的老章帮不上忙,新写两三章之后它才会亮。
  另外,如果你习惯自己先把细纲写好再让它写(细纲所见即所得),那一章就没有「AI 交的那份」
  可比,也攒不出证据。
- **今天只有大纲师这一个人格能学。** 五个人格里,只有大纲师的产物(细纲)是「AI 先交、你再改」
  这个形状,别人的暂时没法比对。
- **想反悔,直接打开 `agents/<角色>.md`、把「## 个人增补」那一段删掉即可**(上面的基座不要动)。
  客户端里暂时没有撤销按钮,得用外部编辑器改——0.5.1 补上。

**修:自带的 DeepSeek 通道写着写着交白卷。** V4 是先想再写的模型,「想」的过程也占额度。
额度按章节字数现算,遇上它想得久的那一步就被想光了,正文一个字没开始写就回来了——
你看到的是这一棒失败。这版把思考的额度按实测的最坏情况给足(**这是 0.4.4 就存在的毛病**)。
自填 base_url 接本地或自建的思考型模型也一起修了:认得出「被想光了」并自动补一次额度重来,
也认得出某些模型把整段正文放错字段的情况。

**修:伙伴落盘后不往下引了。** 你确认一张卡之后,它本该自动接着问下一格;但只要你中途
手打过一次字、越过了某张旧卡,这个自动接续就从此再也不触发,得你自己一直打字催它。

老书零迁移:已有章节照常打开、照常写,盘上一个字不会被改动。只是从这版起,每写一章会在
`正文/.轨迹/` 多留一份底(就是上面「学改法」要比对的那份),拍板增补时会在 `.进化/` 留一份
撤销用的快照——都在书文件夹里,跟着一起备份。

## 0.3.7 有什么

「设了 2000 字,写出来还是忽长忽短」——这一版给字数控制拧上几颗确定性的螺丝。

**字数更听话**
- 编辑/润色现在**知道原稿实际多少字**(以前靠模型自己数,数不准):明显超出发布篇幅(±20%)才带着「超 X%」去压回目标量级、不动情节;还在合格范围的稿不瞎压。
- 改了目标字数后,如果还在用**按旧字数拆的细纲**,会提示你「重新生成细纲」——这是改了字数却不听话最常见的原因。
- 细纲没给各场标字数、或总和跟目标差太多,会提醒你篇幅可能失控。
- 超长提醒更早(超目标 1.25 倍就提,不再等 1.5 倍)、更显眼(专门弹一下,不只默默记留痕)。

**说句实话**:AI 没法边写边精确数字数,单章还会有 ±25-30% 的波动——这是模型的天花板。这一版把「数字数」从模型手里拿回代码手里,尽量逼近你设的目标,但做不到分毫不差。想要某章篇幅精确,手改最稳。

Mac / Windows 都适用,无破坏性改动;老书零迁移。

写长篇最怕的不是写不出,是「第 2 章吞掉的药胚第 4 章又复活了」。这一版给 Loom 装上**除虫闭环**。

- 除虫是放大镜不是保票:报告不自动改稿,「按建议改」要你确认才落盘;别名/简称和没入账的状态可能漏;老书从第 1 章逐章点「除虫」补账;重写过的章,删掉账本里对应「## 第N章」节再扫一次。

- 鼠标移到正文某一行,行边浮出「改」——点开就在那一行下面展开小面板,说一句怎么改(留空=按你的嗓音改顺),候选出来「用这个 / 再来一个」你定;指令框里按 Enter 直接跑。
- 选中一段(跨行也行)照旧浮出朱批条,面板同样就地展开;中央大弹窗退役。
- 铁律不变:AI 改动同步进 .原稿 快照,learn 永远只学你的手改;切文件、换书、手动改文时面板自动收起,候选绝不会落错地方。

**世界观 / 人物也能让 AI 改写、续写**
- 打开世界观或人物文件:选中一段点「改写选中」,或点「AI 续写」顺着现有设定往下铺一节;候选你确认才落盘,不确认不动你一个字。
- 设定改写走设定师口径(与书名、其余设定自洽,不发明冲突),绝不碰你的写作指纹。
- AI 铺完底稿会讲清三种维护方式:随时手改 / 让 AI 改写续写 / learn 后自动追加。

Mac / Windows 都适用,无破坏性改动。

## 0.3.3 有什么

这一版专治「新建一本书,第一章却和书名、想法对不上」——从建书那一刻就把设定铺进去,让第一章一开始就长在你的世界里。老书零迁移、无破坏性改动,升级即生效。

**建书就能定调,AI 一键铺底稿**
- 新建书时可以直接写一句话设定(如「重生成崇祯,开局砍魏忠贤,拯救大明」)、选目标平台;填了设定、模型也接好,进书房就自动按书名 + 设定起草**世界观 / 人物 / 卡章纲**三件套底稿,你改成自己的再开写。
- 起步清单从四步变五步,「AI 铺设定底稿」进了主流程;外置大脑还空着就点「织第一章」会先拦一下、提醒你先铺底稿——直接硬写,AI 只能按题材套路瞎编。

**第一章不再漂移(引擎修复)**
- **模型现在知道这本书叫什么**:书名会写进每一道工序的提示词。以前它对「这本书是什么」一无所知,于是《重生之我是崇祯》能写出个不相干的通用金手指开局。
- **出厂模板不再冒充你的设定**:那些「(占位示例:……)」的填写说明、还空着的表单行,以前会被当成真设定喂给模型、照着执行;现在一律不进提示词——你没填就是没填,AI 按书名 + 题材自由发挥,不照一份错纲跑。
- 历史 / 都市这类题材起草时不再硬套「力量体系 / 金手指」,换成「时代格局 / 主角优势」。

Mac / Windows 都适用,无破坏性改动;老书的外置大脑与写作指纹一字不动。
